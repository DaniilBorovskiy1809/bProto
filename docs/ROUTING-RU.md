# Маршрутизация и выбор серверов

## Панель → подписка → Android

На странице Subscriptions откройте Subscription routing. Укажите сети IPv4
в форме CIDR, IPv4-адреса DNS и имена Android-пакетов, которые должны работать
вне VPN. Сохраните правила и обновите подписку на телефоне. Full tunnel preset
возвращает маршрут `0.0.0.0/0`, DNS `1.1.1.1` и пустой список исключений.
Discard edits отменяет несохранённые изменения.

Пример выборочной маршрутизации:

```json
{
  "routes": ["10.0.0.0/8", "192.168.0.0/16"],
  "dns": ["9.9.9.9"],
  "bypass_apps": ["org.example.browser"]
}
```

В этом примере только перечисленные сети и DNS идут через VPN; остальной
IPv4-трафик использует обычное подключение. Исключённые приложения целиком
работают вне VPN. Это осознанное раскрытие их трафика обычной сети.
DNS получает отдельный маршрут `/32` через VPN даже при выборочных сетях.
IPv6 перехватывается и отбрасывается. Если система отказывает в перехвате IPv6,
VPN не подключается. С доменными правилами и IPv6-маршрутизацией эта версия
не работает. Android Always-on VPN с блокировкой соединений без VPN может
ограничивать трафик, намеренно исключённый из туннеля.

## Клиент с глобусом

Вставьте HTTPS-ссылку подписки и нажмите подключение. Клиент запрашивает JSON
по умолчанию, чтобы получить правила маршрутизации. Выберите сервер, затем
нажмите глобус. Повторное нажатие отключает VPN или отменяет попытки подключения.
Кнопка выбора сервера повторно открывает импортированный список.

Automatic перебирает серверы в порядке подписки до первого успешного
аутентифицированного рукопожатия. Это не измерение лучшего ping и не фоновое
переключение после обрыва уже установленного соединения. Таймауты рукопожатий
складываются при недоступности нескольких серверов. Во время автоматического
выбора используется политика выбранного профиля для всех попыток.

Routing settings меняет правила выбранного профиля на устройстве. Reset to
full tunnel возвращает значения по умолчанию. Повторный импорт подписки заменяет
профили и локальные изменения правил. Forget profiles удаляет сохранённый список
после подтверждения. Профили шифруются ключом Android Keystore; перенос файла
на другое устройство не переносит ключ расшифрования.

## Ограничения белых списков

Маршрутизация и автовыбор не создают доступ к заблокированному серверу.
Если оператор разрешает только определённые IP, сервисы или протоколы, обычный
UDP-сервер может быть недоступен. Поле SNI не меняет этого. Реальной гарантии
обхода белых списков в этой версии нет; переключатель с таким обещанием
не добавлен. Проверяйте доступность конкретных серверов в целевой сети.

Подписка содержит секретные ключи: передавайте URL только по HTTPS и не
публикуйте её в логах, скриншотах или обращениях в поддержку.
