# bProto 2.0.0 — Orbit

## Русский

Главное изменение относительно v1.5.0 — обновлённый Android-клиент:

- Тёмная графитовая тема с мятными акцентами и единым оформлением диалогов.
- Глобус с крупной кнопкой питания и разными состояниями подключения.
- Карточка выбранного сервера и число сохранённых профилей.
- Раскрываемый блок добавления ключей и подписок.
- Понятные статусы ожидания, импорта, подключения и активного туннеля.
- Русские и английские подписи, поддержка системных отступов и вырезов экрана.
- Сохранены маршрутизация, зашифрованные профили и аутентифицированный автовыбор.

Версии Rust-компонентов, панели и Android синхронизированы до 2.0.0;
Android versionCode — 20000. Bootstrap по умолчанию скачивает v2.0.0.
Это выпуск интерфейса; новая версия не добавляет новый wire protocol,
доменную маршрутизацию или гарантированный обход блокировок.

## English

The main change since v1.5.0 is the redesigned Android Orbit client:

- Graphite dark theme, mint accents and consistent dialogs.
- Globe connection control with a prominent power symbol and connection states.
- Selected-server card and saved-profile count.
- Collapsible key/subscription import panel.
- Clear disconnected, importing, connecting and connected states.
- Russian/English labels and system-bar/display-cutout insets.
- Existing routing, encrypted profiles and authenticated server fallback retained.

Rust, panel and Android versions are 2.0.0; Android versionCode is 20000.
Bootstrap defaults to v2.0.0. This is a UI release; it does not introduce a new
wire protocol, domain-routing engine or guaranteed censorship bypass.

## Installation / Установка

Run in a root shell on a supported x86_64 Ubuntu 24.04+/Debian 13+ VPS:
Выполните из root-оболочки на поддерживаемом x86_64 VPS:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/dr-lexus-dr/bProto/v2.0.0/bootstrap.sh)
```

Read README.md for firewall, NAT, public endpoint and separate panel installation.
Настройки firewall, NAT, публичного адреса и отдельная установка панели — в README.md.

## Upgrade and validation limits / Ограничения обновления и проверок

The Android APK is debug-signed. Its signing key may differ from an earlier CI
build: updating can require uninstalling the old app. Preserve your subscription
before uninstalling, because encrypted device profiles will be removed.

APK имеет debug-подпись. При несовпадении ключа обновление поверх прежнего APK
невозможно; сохраните подписку перед удалением приложения.

The redesign compiled and passed 14 JVM tests before release preparation.
Publication is gated by fresh Android, Linux/panel and installer CI jobs.
No visual verification on an emulator/physical device or real VPS installation
was performed in this task. No guaranteed allowlist bypass is implemented;
manual panel-to-server key synchronization remains required.

Внешний вид на устройстве и установка на реальном VPS в этой задаче не проверялись.
Гарантированный обход белых списков не реализован; ключи панели по-прежнему
нужно синхронизировать с сервером вручную.
