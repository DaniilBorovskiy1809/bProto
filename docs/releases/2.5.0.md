# bProto 2.5.0 — Orbit transports

## Русский

Выпуск добавляет экспериментальные TLS 1.3, HTTP/3 и WSS поверх существующего
протокола bProto. Native UDP остаётся исходным режимом.

- Android: TLS/WSS и native QUIC через JNI, защита внешнего сокета до подключения.
- HTTP/3: quinn/h3-клиент и aioquic-сервер, Retry, проверка сертификатов.
- ECH: обязательный режим клиента QUIC, срок действия публичной конфигурации,
  отказ без downgrade; автовыбор исключает обычные профили при требовании ECH.
- Панель: экспорт TLS/WSS/QUIC Android-профилей, ECH-настройки.
- Агент: mTLS, атомарное применение TLS-конфигурации, health и rollback.
- Исправления: адрес клиента обновляется только после аутентификации/replay-проверки;
  UDP upstream закрывается при остановке HTTP/3-сервера.
- Новый README с локальным SVG-баннером, инструкции RU/EN.

Проверки перед выпуском: Rust core, Android JVM, Python carrier/agent suites,
Rust↔aioquic interoperability, сборки трёх ABI, APK и панели. Точный результат
CI относится к SHA тега. JVM и локальные проверки не заменяют Android device e2e.

### Ограничения выпуска

Полный PLAN-2.5.md остаётся открытым. Не подтверждены успешное принятие ECH,
новые транспорты через VpnService на устройстве, живая CDN/сеть РКН и
браузерные JA3/JA4-профили. Python-сервер не принимает ECH. Нет ECH DNS discovery,
автоматической ротации и crash recovery агента. Apply панели — только TLS.
Это выпуск экспериментальных функций, не утверждение о завершении исследования.

Гарантии обхода РКН/белых списков нет. Нужен свой доступный домен/сертификат.
APK подписан debug-ключом CI; совместимость обновления с другими debug-подписями
не гарантируется. Native UDP установлен обычным bootstrap; дополнительные
мосты настраиваются по инструкциям tools/, автоматически не включаются.

## English

2.5.0 adds experimental TLS 1.3, HTTP/3 and WSS carriers around the unchanged
bProto protocol, Android protected-socket integration, required ECH client policy,
panel profile exports and an mTLS configuration agent with health/rollback.

The full research roadmap remains open. Successful ECH acceptance, Android device
VpnService tests for new carriers, live CDN/RKN validation and browser JA3/JA4
profiles are not verified. The Python server cannot terminate ECH. DNS ECH
discovery/rotation and agent crash recovery are absent. Panel Apply targets TLS.
This release publishes experimental functionality, not a completed evasion claim.

No guaranteed censorship or allowlist bypass. Use an owned hostname and valid
certificate. The APK is CI debug-signed; upgrades across debug keys may require
reinstallation. Bootstrap installs native UDP; deploy carriers explicitly using
the RU/EN instructions under tools/. SHA256SUMS covers release assets.
