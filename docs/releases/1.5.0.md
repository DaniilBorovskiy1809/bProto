# bProto 1.5.0

## Русский

Обновление установки и документации после v1.0.0.

- Новый `bootstrap.sh`: установка сервера и Linux CLI одной командой без Rust.
- Скачивание готового релиза с проверкой SHA256, режимы dry-run и download-only.
- Проверка платформы, glibc, TUN и зависимостей; сохранение существующей конфигурации.
- Исправлены права чтения server.toml сервисом и capability для UDP 443.
- Повторная установка сохраняет panel/.env, обновление перезапускает службу.
- Ошибка запуска systemd возвращает ошибку установки.
- Большой README на русском и английском: установка, клиенты, панель,
  маршрутизация, ключи, backup, upgrade, rollback и диагностика.
- Пять безопасных тестов установщика включены в CI и блокируют публикацию при сбое.
- Версии Rust, панели и Android обновлены до 1.5.0; Android versionCode 10500.

Установка на x86_64 Ubuntu 24.04+/Debian 13+ из root-оболочки:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/dr-lexus-dr/bProto/v1.5.0/bootstrap.sh)
```

Bootstrap устанавливает сервер и CLI, панель — отдельной командой из README.
Проверьте firewall, публичный endpoint и NAT-интерфейс после установки.

## English

Installation and documentation update since v1.0.0.

- Standalone bootstrap installs the server and Linux CLI without Rust.
- Verified release downloads, dry-run/download-only modes and host preflight checks.
- Service configuration permissions and privileged UDP-port capability fixed.
- Existing panel credentials/configuration are retained; upgrades restart the service.
- Service startup failures return an installation error.
- Extensive Russian/English operations README and five installer CI contract tests.
- Rust, panel and Android versions set to 1.5.0; Android versionCode 10500.

Use the command above from a root shell on an x86_64 Ubuntu 24.04+/Debian 13+
host. The panel is installed separately; verify firewall, endpoint and NAT settings.

## Assets / Файлы

- `bproto-1.5.0-debug.apk`: Android arm64-v8a, armeabi-v7a, x86_64.
- `bproto-linux-x86_64.tar.gz`: Linux server, CLI, library and panel.
- `bproto-v1.5.0-source.tar.gz`: sources, bootstrap, installer and documentation.
- `SHA256SUMS`: checksums using the downloaded asset filenames, without subdirectories.

## Limits / Ограничения

Android APK is debug-signed, not signed with a persistent release distribution key.
Updating from a differently signed APK can require uninstalling it; preserve your
subscription first. Physical-device and real systemd/TUN VPS installation testing
was not performed in this task. Installer contracts and verified downloads are
not a substitute for a deployment test. Native transport disguise and guaranteed
allowlist/censorship bypass are not implemented. Panel-to-server key synchronization
still requires the documented manual step. These limitations also apply to 1.5.0.
